Memoria persistente
per i tuoi agenti AI.

Architettura

Quattro livelli, una sola direzione di dipendenza

Clean Architecture: Domain non conosce nulla del resto, Application definisce i casi d'uso tramite interfacce, Infrastructure li implementa con EF Core e i provider di embedding, Api espone tutto via Model Context Protocol.

◆

Multi-tenant per spazio

Ogni API Key ha un permesso Read/ReadWrite per spazio e uno spazio "attivo" di default. Isolamento garantito a livello di query.

◇

Ricerca semantica

Similarità coseno tra embedding calcolata in-app, su una colonna Postgres real[] nativa — nessuna estensione richiesta.

○

Embedding pluggable

IEmbeddingProvider astrae OpenAI e Azure OpenAI dietro lo stesso EmbeddingClient, risolto lazy per non bloccare i tool che non ne hanno bisogno.

Nota tecnica: la specifica prevedeva PostgreSQL + pgvector con indice HNSW. In questo ambiente Docker è bloccato da policy aziendale e il Postgres locale non ha l'estensione installata (né è installabile senza permessi di amministratore), quindi la ricerca è stata implementata senza estensioni esterne. Funziona correttamente, ma non scala quanto un indice vettoriale nativo su volumi molto grandi.

Tool MCP

7 tool, coerenti con la specifica

Ogni tool è un thin adapter: risolve il contesto di accesso, chiama il servizio applicativo, formatta l'output.

search_memoryRead

Ricerca semantica tra le memorie di uno spazio, con profilo stabile/recente opzionale.

add_memoryReadWrite

Salva (save) o rimuove (forget) una memoria in base al contenuto.

listMemoriesRead

Elenco paginato delle memorie estratte in uno spazio.

listDocumentsRead

Elenco paginato dei documenti sorgente di uno spazio.

getDocumentRead

Metadati e contenuto disponibile di un singolo documento.

listSpaces—

Spazi accessibili dalla API Key corrente, con livello di accesso e conteggi.

whoAmI—

Identità corrente, spazi accessibili, spazio attivo.

Getting started

Setup in locale in 4 passi

1

Configura la connection string

# src/MemoryMcp.Api/appsettings.Development.json (non versionato){ "ConnectionStrings": { "Default": "Host=localhost;Port=5432;Username=...;Password=...;Database=..." } }
2

Applica le migration

$ dotnet ef database update --project src/MemoryMcp.Infrastructure --startup-project src/MemoryMcp.Api
3

Crea uno spazio e una API Key di test

$ dotnet run --project src/MemoryMcp.Api -- --seed# Seeded space 'default' with API key: mmcp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
4

Avvia il server

$ dotnet run --project src/MemoryMcp.Api# http://localhost:5004/mcp — richiede header X-Api-Key
